# Contributing

- Keep pull requests focused and explain the motivation.
- Follow Clean Architecture and MVVM with Jetpack Compose and Kotlin.
- Never commit API keys, signing keys, keystores or personal data.
- Audius is the sole authorized online music discovery and streaming provider.
- Include loading, empty, error and success states for asynchronous UI.
- Run Gradle unit tests and Android lint before submitting changes.
- Ensure 100% offline playback functionality for local MediaStore tracks.
