# Contributing

- Keep pull requests focused and explain the motivation.
- Follow feature-first architecture and add tests for behavior changes.
- Never commit API keys, signing keys, keystores or personal data.
- Do not add YouTube audio extraction, downloading or unofficial stream endpoints.
- Include loading, empty, error and success states for asynchronous UI.
- Run `dart format .`, `flutter analyze` and `flutter test`.
- Respect YouTube attribution and API policy requirements.
