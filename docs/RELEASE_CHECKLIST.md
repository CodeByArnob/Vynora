# Release readiness checklist

This checklist is not a claim that release approval has been achieved.

- [ ] Pin and document Flutter SDK version
- [ ] Clean CI dependency resolution succeeds
- [ ] Dart formatting and flutter analyze pass
- [ ] Unit, widget and integration tests pass
- [ ] Release APK/AAB builds successfully
- [ ] Test on physical devices and supported Android API levels
- [ ] Android media permissions requested only when needed
- [ ] Local playback, audio focus, interruptions and notification controls tested
- [ ] No YouTube audio extraction or background playback
- [ ] YouTube attribution, API terms and branding reviewed
- [ ] API key restrictions and quota alerts configured
- [ ] Privacy policy and Data safety disclosures completed
- [ ] App icon, screenshots, store listing and signing configured
- [ ] Offline, empty, timeout and quota-exceeded states verified
